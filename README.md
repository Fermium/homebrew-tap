# Fermium Homebrew tap

```sh
brew install --cask fermium/tap/peel-good-inc     # Peel Good Inc., the menu bar label printer app
brew install fermium/tap/peelgood             # just the labelize command-line tool
```

The cask is updated automatically when [Peel Good Inc.](https://github.com/fermium/peel-good-inc) is released.
